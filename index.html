            Updates & Changelog

            CURRENT RELEASE

            V15.0 — Performance, Detection & Cloud Sync

            • All-new interface: a sidebar-based dashboard, redesigned game cards, and responsive layouts.

            • Personal library: favorites, persistent recent-game history, launch stats, and achievements.

            • 120 FPS canvas cap: Launchpad background effects are paced at up to 120 rendered frames per second on supported displays.

            • Cloud accounts: Supabase email/password authentication, per-user cloud saves, automatic sync, and upload/restore controls. (BETA)

            • Diagnostics: browser, device, graphics, storage, and network capability detection.

            • Usability fixes: safer persistence, keyboard-friendly controls, and quick-launch actions.

            V13.0 - The Meme & Engine Overhaul

            • Meme Flying Mode Added: Built-in flying floating meme overlay system (off by default) bouncing dynamically across the screen!

            • Performance Optimization: Refactored animation frames with hardware-accelerated canvas loops, debounced search, and zero lag.

            • UI Refresh: A clean, flat interface, reduced visual effects, responsive navigation, and lighter controls.

            V12.0 - The Visual Refresh

            • Visual Overhaul: Introduced an experimental translucent interface in the previous release.

            • Optimized Rendering: Particle system updated to use soft ambient orbs for a smoother visual background.

            Database setup SQL (run once in Supabase SQL Editor)

            Create a table with Row Level Security so each signed-in user can only read and write their own Launchpad save.

            create table if not exists public.launchpad_profiles (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);

alter table public.launchpad_profiles enable row level security;

drop policy if exists "Users manage their own Launchpad save" on public.launchpad_profiles;
create policy "Users manage their own Launchpad save"
on public.launchpad_profiles
for all to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

grant select, insert, update, delete
on public.launchpad_profiles to authenticated;

            For production, host this page over HTTPS, enable email confirmation as desired, and keep Row Level Security enabled. A public anon key is designed for browser use only when database policies are correctly configured.
