            RELEASE NOTES

            Updates & Changelog

            CURRENT RELEASE

            V15.5 — about:blank Engine, Custom Library & UI Overhaul

            • about:blank Launcher: Open the entire hub or individual games inside cloaked about:blank tabs with automatic title & icon inheritance.

            • Unified Design System: Consolidated stylesheets, responsive mobile drawer navigation, and automatic GPU pause when playing embedded games.

            • Custom Game Library: Add your own game URLs locally alongside all 39 built-in arcade classics.

            • Smart Command Palette: Search and launch any game or system command directly from Ctrl+K.

            V15.0 — Local Saves, Performance & Detection

            • Personal library: favorites, persistent recent-game history, launch stats, and achievements.

            • 120 FPS canvas cap: Launchpad background effects are paced at up to 120 rendered frames per second on supported displays.

            • Diagnostics: browser, device, graphics, storage, and network capability detection.

            V13.0 — The Meme & Engine Overhaul

            • Meme Flying Mode Added: Built-in flying floating meme overlay system bouncing dynamically across the screen.

            • Performance Optimization: Hardware-accelerated canvas loops and debounced search.
